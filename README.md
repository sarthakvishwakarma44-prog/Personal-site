## 🌟 About the Project

**Stardance Learning Hub** is an interactive educational website designed to help beginners learn web development in a simple and easy-to-understand way.

The main goal is:

> **Make programming easy enough that beginners can learn without feeling confused.**

The website teaches:

- 🌐 HTML
- 🎨 CSS
- ⚡ JavaScript

Each subject is divided into different learning levels.
